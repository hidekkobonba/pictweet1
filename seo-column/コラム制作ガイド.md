## 3. デザイン（グリーン×白×ゴールド）
- カラートークンは各HTMLの `:root` にある（`--green` `--accent`(ゴールド) `--ink` など）。ライト/ダーク両対応。
- **新記事は既存記事をコピーして作る**のが速い（`<style>`ブロックをそのまま流用）。
- 共通パーツ：sticky header、パンくず、`.supervisor`（監修欄）、`.toc`（目次）、`.article h2`（Section番号付き）、
  `.voice`（院長コメント）、`.cards`、`table.data`、`.risk`、`ol.flow`（タイムライン）、`.faq`、`.author-box`、
  `.related`、`.cta-band`、`.ig-link`、`.ig-embed`、症例の `.case`/`.case-photos`/`.photo-slot`（スマホは横スワイプ）。
- スマホ最適化の `@media(max-width:600px)` あり。h1の強制改行は `<br class="br-pc">`。

## 4. 新記事の作り方（レシピ）
1. 既存記事（例 `dango-hana-fukuoka.html`）をコピー。
2. `<head>` を差し替え：`<title>` / meta description / canonical / og:* / **JSON-LD（Breadcrumb・MedicalWebPage・FAQPage）**。
3. パンくず3つ目、breadcrumb JSON-LDの3つ目（記事名・URL）を更新。
4. 本文（`<article>`）を新テーマで作成。基本構成：導入→原因/解説→当院の方法（院長voice）→症例→費用→ダウンタイム→リスク→FAQ→著者→関連→CTA。
5. `.related` は**実在ページのみ**リンク（`#`や未作成ページを残さない）。
6. `index.html` にカードを1枚追加（サムネ画像・タグ・タイトル・説明）。関連リンクも相互に繋ぐ。
7. プレビュー生成→公開（下記ワークフロー）。commit & push。

## 5. 画像・動画・プレビューの手順（Python/Pillow）
Pillow が要る場合：`python3 -m pip install --quiet Pillow`

**本番画像の最適化**（アップされた素材 → 軽量JPEG）
- EXIF補正 → 長辺1400pxにリサイズ → JPEG q84 progressive。ファイル名は記事の参照名に合わせる。
- 命名規則：`hero.jpg` / `illust-*.jpg` / 症例 `case-<topic>-front|oblique|side.jpg` / `hane.jpg` / `ogp.jpg`(任意)
- 図解の中に説明文が入っているので、図解の `<figcaption>` は付けない（重複するため）。

**プレビュー（claude.ai artifact）**：外部画像・iframeはCSPで表示されないので、
記事HTMLの `src="images/X.jpg"` を **base64 data URI**（長辺900・q72〜74）に置換した版を publish する。
→ 画像は出るが、**Instagram埋め込み動画はプレビューでは出ない**（本番/ローカルで出る）。

**リール動画**：Instagram**公式embed**を使う（自動サイズ調整。固定iframeは縦潰れNG）。
```html
<figure>
  <blockquote class="instagram-media" data-instgrm-permalink="https://www.instagram.com/reel/ID/" data-instgrm-version="14" style="max-width:400px;width:calc(100% - 2px);min-width:280px;margin:22px auto">
    <a href="https://www.instagram.com/reel/ID/" target="_blank" rel="noopener noreferrer" style="display:block;padding:22px;text-align:center;color:#8C6C25;text-decoration:none">Instagramでリールを見る →</a>
  </blockquote>
  <figcaption>◯◯の様子（<a href="https://www.instagram.com/reel/ID/" target="_blank" rel="noopener noreferrer">院長Instagramで見る →</a>）</figcaption>
</figure>
```
- `</body>` 直前に一度だけ：`<script async src="//www.instagram.com/embed.js"></script>`
- **キャプションに「動画：」プレフィックスは付けない**（ユーザー指定）。「上の症例を院長が解説しています」等。
- 患者インタビュー（体験談）は医療広告ガイドラインで要注意 → 事実ベース＋「※効果・感じ方には個人差があります」。

## 7. ポジショニング（記事の“軸”）
- クローズド法が軸だが「**変化量から逃げない**（自然一辺倒ではない・派手も作れる）」。
- **肋軟骨を自家採取できる**＝保存軟骨/耳介軟骨に安易に逃げない、素材で妥協しない。
- **全方向（正面・斜め・横）の症例公開**＝技術への自信・透明性。
- 「傷が表に出ない／ダウンタイム短め／皮膚を閉じたまま整えるので仕上がりが安定」。
- **「閉鎖式」＝クローズド法と同じ**もの（競合eクリニックの造語。術式の優劣差はない）。
- 「バレない＝小さくしか変えない」ではない。顔全体の調和で設計。
