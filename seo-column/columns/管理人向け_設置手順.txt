============================================================
 Zetith Beauty Clinic  コラム設置手順（管理人さま向け）
                                    ※ 最新版（モバイルファースト刷新）
============================================================

鼻整形コラム 全8ページ（一覧＋記事7本）と、使用画像（images）、
共通デザインファイル（assets）が入っています。院長の顔写真・
Instagramリンク・リール動画（埋め込み）も設定済みです。

------------------------------------------------------------
■ フォルダ構成（この位置関係のまま、まるごとアップしてください）
------------------------------------------------------------

  columns/
   ├─ index.html                    … コラム一覧（トップ）      → /columns/
   ├─ fukuoka-hana-seikei.html      … 柱：クローズド法 総合      → /columns/fukuoka-hana-seikei
   ├─ hana-seikei-jutsushiki.html   … 術式まるわかりガイド(ハブ) → /columns/hana-seikei-jutsushiki
   ├─ bichukaku-encho-fukuoka.html  … 鼻中隔延長                → /columns/bichukaku-encho-fukuoka
   ├─ kizoku-shujutsu-fukuoka.html  … 貴族手術                  → /columns/kizoku-shujutsu-fukuoka
   ├─ dango-hana-fukuoka.html       … 団子鼻                    → /columns/dango-hana-fukuoka
   ├─ hana-seikei-barenai.html      … バレない・傷跡             → /columns/hana-seikei-barenai
   ├─ hana-seikei-downtime.html     … ダウンタイム              → /columns/hana-seikei-downtime
   ├─ assets/                        … 共通デザイン（全ページ共通）
   │    ├─ columns.css               … スタイル（白×深緑×ゴールド／ライト・ダーク対応）
   │    └─ columns.js                … 目次開閉・症例タブ・絞り込み等（軽量）
   └─ images/                        … 各ページが読み込む画像
        ├─ hero.jpg / ogp.jpg(任意)
        ├─ hane.jpg                  … 院長の顔写真
        ├─ illust-*.jpg (図解)
        └─ case-*.jpg (症例)

  ★ HTML・assets・images は必ず「セット」で、同じ位置関係のまま設置。
    バラすとデザインや画像が崩れます。

------------------------------------------------------------
■ 設置手順（3ステップ）
------------------------------------------------------------

 1. サーバーの公開フォルダに「columns」フォルダをまるごとアップロード
    （assets も images も一緒に、同じ位置関係で）。

 2. 各ページは上記のURL（拡張子なし）で開ける想定です。
    ※ サーバーが拡張子なしURL（クリーンURL）に対応していない場合は、
      制作側にご連絡ください。「.html 付きURL」版に一括変更してお渡しします。

 3. 福岡院トップページ等から、コラム一覧へリンクを設置。
      例）<a href="/columns/">コラム</a>

------------------------------------------------------------
■ 動画（Instagramリール）について
------------------------------------------------------------

  一部の記事（団子鼻・バレない・ダウンタイム）にInstagramのリール動画を
  「埋め込み」で設置しています。
  ・動画ファイルの用意は不要です（Instagramから読み込まれます）。
  ・対象リールがInstagramで「公開」設定である必要があります。
  ・環境でInstagram表示がブロックされている場合は、各動画下の
    「Instagramで見る →」リンクから視聴できます。

------------------------------------------------------------
■ 公開前に差し替える箇所（各HTMLの <head> 内）
------------------------------------------------------------

  ・ canonical と og:url  … 実際の公開URLに合わせて確認・修正
  ・ og:image（SNSサムネ）… images/ogp.jpg を用意する場合は images に追加（任意）

  ※ 住所・電話番号・予約URL・LINE・Instagram（@zetith_hane）・院長写真は設定済みです。
  ※ 全8ページとも公開可能な状態です（以前ご案内した「貴族手術ページの公開保留」は解消済み）。

------------------------------------------------------------
■ WordPress で運用している場合
------------------------------------------------------------

  画像はメディアライブラリにアップ、assets/columns.css・columns.js もアップして
  各HTMLの読み込みパスを合わせてください。本文（<main>...</main>）を
  固定ページに貼る運用の場合は、テーマ側で columns.css / columns.js を読み込む形にします。

------------------------------------------------------------
■ 公開後（SEOのために）
------------------------------------------------------------

  ・ Google Search Console に各ページのURL（8つ）を登録（インデックス登録）
  ・ sitemap.xml に各URLを追加

  ご不明点は制作側までお気軽にご連絡ください。
