============================================================
 Zetith Beauty Clinic  コラム設置手順（管理人さま向け）
                                         ※ 最終版
============================================================

鼻整形コラム 全5ページ（一覧＋記事4本）と、使用画像（images・14枚）が
入っています。院長の顔写真・Instagramリンク・リール動画（埋め込み）も
設定済みです。

------------------------------------------------------------
■ フォルダ構成（この位置関係のまま、まるごとアップしてください）
------------------------------------------------------------

  columns/
   ├─ index.html                 … コラム一覧（トップ）  → /columns/
   ├─ fukuoka-hana-seikei.html   … 柱：クローズド法 総合 → /columns/fukuoka-hana-seikei
   ├─ dango-hana-fukuoka.html    … 団子鼻               → /columns/dango-hana-fukuoka
   ├─ hana-seikei-barenai.html   … バレない・傷跡        → /columns/hana-seikei-barenai
   ├─ hana-seikei-downtime.html  … ダウンタイム          → /columns/hana-seikei-downtime
   └─ images/                     … 上記が読み込む画像（14枚）
        ├─ hero.jpg / ogp.jpg(任意)
        ├─ hane.jpg               … 院長の顔写真
        ├─ illust-*.jpg (図解3枚)
        └─ case-*.jpg (症例9枚)

  ★ HTMLと images フォルダは必ず「セット」で、同じ位置関係のまま設置。
    バラすと画像が表示されません。

------------------------------------------------------------
■ 設置手順（3ステップ）
------------------------------------------------------------

 1. サーバーの公開フォルダに「columns」フォルダをまるごとアップロード
    （images も一緒に、同じ位置関係で）。

 2. 各ページは上記のURL（拡張子なし）で開ける想定です。
    ※ サーバーが拡張子なしURL（クリーンURL）に対応していない場合は、
      制作側にご連絡ください。「.html 付きURL」版に一括変更してお渡しします。

 3. 福岡院トップページ等から、コラム一覧へリンクを設置。
      例）<a href="/columns/">コラム</a>
    （コラム内のロゴ／「ホーム」は福岡院トップ /ja-jp/clinics/fukuoka/ へ、
      「コラム」は一覧 /columns/ へ、すでに繋いであります）

------------------------------------------------------------
■ 動画（Instagramリール）について
------------------------------------------------------------

  記事内にInstagramのリール動画を「埋め込み」で設置しています。
  ・動画ファイルの用意は不要です（Instagramから読み込まれます）。
  ・閲覧環境でInstagramの表示がブロックされている場合は、各動画の下の
    「Instagramで見る →」リンクから視聴できます。

------------------------------------------------------------
■ 公開前に差し替える箇所（各HTMLの先頭にコメントで記載）
------------------------------------------------------------

  ・ canonical と og:url  … 実際の公開URLに合わせて確認・修正
  ・ og:image（SNSサムネ）… images/ogp.jpg を用意する場合は images に追加（任意）

  ※ 住所・電話番号・予約URL・LINE・Instagram（@zetith_hane）・院長写真は設定済みです。

------------------------------------------------------------
■ WordPress で運用している場合
------------------------------------------------------------

  画像はメディアライブラリにアップし、HTML内の src="images/○○.jpg" を
  アップ後のURLに置き換えてください。本文（<article>...</article>）を
  固定ページに貼る運用でもOKです。

------------------------------------------------------------
■ 公開後（SEOのために）
------------------------------------------------------------

  ・ Google Search Console に各ページのURL（5つ）を登録（インデックス登録）
  ・ sitemap.xml に各URLを追加

  ご不明点は制作側までお気軽にご連絡ください。
