# ゼティス羽根 Instagram 投稿構成案（鼻整形シリーズ）

> 各投稿は **カルーセル（複数枚スライド）** 前提の構成案です。
> 「術式編」→「悩み編」の2軸で展開し、相互に回遊させます。
> ※医療情報の最終表現・数値（ダウンタイム日数、料金等）は**医師監修で確定**してから投稿してください。本資料は構成のたたき台です。

---

## 0. 全体戦略

| 軸 | 役割 | 狙うユーザー | KPI |
|---|---|---|---|
| **術式編**（全18本） | 教育・信頼構築・比較検討 | 検討が進んでいる人 | 保存・プロフ遷移・予約 |
| **悩み編**（お渡し資料準拠） | 入口・共感・リーチ | まだ何も知らない人 | リーチ・新規フォロー・保存 |

**回遊の仕掛け**
- 悩み編の最後 → 「解決する術式はコチラ →（術式編へ誘導）」
- 術式編の最後 → 「あなたの悩みから探す →（悩み編へ誘導）」
- ハイライトを「術式編」「悩み別」「症例」「料金」で整理

## 1. 投稿順（推奨）

導入として「アプローチ編」を先に出し、土台を作ってから各術式へ。

```
【導入編】① クローズド法  ② オープン法
【鼻先】 鼻尖形成 → 軟骨移植 → ストラット → 鼻中隔延長(耳) → 鼻中隔延長(肋)
【鼻筋】 プロテーゼ → 自家組織隆鼻 → 骨切り幅寄せ → 鷲鼻削り・ハンプ切除
【小鼻・鼻孔・鼻柱】 鼻翼縮小 → 鼻孔縁挙上 → 鼻孔縁下降 → 鼻翼挙上 → 鼻柱下降
【周辺・その他】 貴族手術(ゴア) → 貴族手術(肋) → 猫手術
↓
【悩み編】お渡し資料の目次順（鼻先 → 鼻筋 → 小鼻・鼻の穴 → 全体・横顔 → 専門・顔立）
```

8. **症例（Before / After）** … ※同意取得済みのみ・要注意書き
9. **まとめ＋CTA** … 「DM/プロフィールから無料カウンセリング」

### 悩み編 共通スライド構成（6〜8枚）

4. **その鼻が与える“印象”** … お渡し資料の「印象」列を活用（華やか/可愛い等）
5. **解決する術式** … 該当術式へ誘導（術式編リンク）
6. **症例 Before / After**
7. **費用・ダウンタイムの目安**
8. **まとめ＋CTA**

# 第1部：術式編

---

## 導入編① クローズド法
- **表紙キャッチ**：「傷が見えない鼻整形｜クローズド法とは？」
1. 表紙
2. クローズド法とは（鼻の穴の中だけを切開＝外から傷が見えない）
3. メリット（傷が目立たない／腫れが比較的少ない／時間が短い傾向）
4. デメリット（視野が狭く繊細な操作に限界／適応が限られる）
5. 向いている手術（プロテーゼ・軽度の鼻尖形成 など）
6. オープン法との違い（次回予告として比較表の一部）
7. まとめ＋CTA

## 導入編② オープン法
- **表紙キャッチ**：「複雑な鼻整形の基本｜オープン法とは？」
1. 表紙
2. オープン法とは（鼻柱を小さく切開し皮膚を起こして直視下で操作）
3. メリット（正確・左右差調整に強い／複雑な構造手術が可能）
4. デメリット（鼻柱に傷／腫れがやや長い傾向）
5. 向いている手術（鼻中隔延長・複雑な鼻尖形成・修正術 など）
6. クローズド vs オープン 比較表（傷・適応・ダウンタイム）
7. まとめ＋CTA

# 第2部：悩み編（お渡し資料「お悩み・印象 目次」準拠）

> 資料の5カテゴリ（鼻先／鼻筋／小鼻・鼻の穴／全体・横顔／専門・顔立）に沿って展開。
> 各投稿で「印象」列（華やか・可愛い 等）を**Before印象 → After印象**として見せると刺さります。
> ※下記の悩み項目・印象ワード・該当術式は、お渡し資料の実データに合わせて差し替えてください。

## 共通：悩み編の“勝ちパターン”スライド
1. 表紙「〇〇な鼻、印象は△△に見られがち」
2. あるある共感
3. 原因（骨/軟骨/皮膚/脂肪のどれか）解剖図
4. 印象の変化（Before印象 → After印象）
5. 解決する術式（→術式編へリンク）
6. 症例 Before/After
7. 費用・ダウンタイム目安
8. まとめ＋CTA

### 【鼻先】
- **団子鼻** → 解決術式：鼻尖形成＋軟骨移植（必要に応じストラット）
- **鼻先の丸み** → 鼻尖形成
- **鼻先の大きさ** → 鼻尖形成（＋軟骨移植）

### 【鼻筋】
- **鼻筋の高さ（低い）** → プロテーゼ／自家組織隆鼻
- **わし鼻（鷲鼻）** → ハンプ切除（＋骨切り幅寄せ）
- **鼻筋の太さ** → 骨切り幅寄せ

### 【小鼻・鼻の穴】
- **小鼻の大きさ** → 鼻翼縮小
- **鼻の穴が目立つ** → 鼻翼縮小／鼻孔縁挙上
- **四角鼻** → 鼻尖形成＋鼻翼まわり

### 【全体・横顔】
- **上向き・短い鼻（豚鼻）** → 鼻中隔延長（耳/肋）
- **鼻の長さ・横顔バランス** → 鼻中隔延長／鼻柱下降
- **のっぺり・凹凸不足** → プロテーゼ＋鼻尖形成（トータル）

### 【専門・顔立】
- **左右差・曲がり鼻** → 骨切り＋鼻中隔（修正系）
- **先天的・難症例** → 肋軟骨を用いた構造手術

## 3. 運用メモ
- デザインテンプレ（表紙の色・フォント・ロゴ位置）を**全投稿で統一**＝シリーズ感＝保存・フォローに効く
- 症例写真は**同意取得済みのみ**・広告規制（医療広告ガイドライン）に配慮（ビフォーアフターには説明文・リスク・費用の明記が必要）
- 各投稿キャプション末尾に固定CTA＋ハッシュタグセット（部位別タグを用意）
- 数値（ダウンタイム・料金）は**医師監修で確定後**に記載
